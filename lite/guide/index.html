מדריך למשתמש

כל מה שצריך כדי להתחיל ולעבוד עם LessonDone Lite.

1. לפני שמתחילים

  • גיליון ב-Google Sheets. קובץ Excel במחשב? פותחים sheets.google.com ← קובץ ← ייבוא ← מעלים את הקובץ.
  • בגיליון צריכות להיות עמודת תאריך ועמודת סכום לכל שיעור, ושם התלמיד/ה — בעמודה, או כשם הלשונית (לשונית לכל תלמיד/ה). התוסף מזהה את העמודות לבד.
  • טלפון: אנדרואיד 7.0 ומעלה, או אייפון 11 ומעלה עם iOS 27. טלפון ישן יותר — "מצב ידני" (כל השאר עובד, את התשלומים רושמים בלחיצה).
  • Bit ו/או PayBox מותקנות בטלפון, מחוברות, וההתראות שלהן דלוקות — לפני שמחברים את הטלפון. תשלום שהגיע לפני שהאפליקציה הותקנה לא נקלט לבד; רושמים אותו ידנית (סעיף 6).
  • לתזכורות להורים (לא חובה): חשבון ב-GREEN API (סעיף 7).

2. התקנה (כ-2 דקות)

  1. פותחים את הגיליון ← תוספים ← LessonDone Lite ← נפתח סרגל צד משמאל.
  2. שלב 1 — פרטים: שם, טלפון, סוג הטלפון, ואילו אפליקציות תשלום יש לך.
  3. שלב 2 — הגיליון: התוסף מזהה את העמודות ומציג מה מצא. לא זוהה? כותבים לנו.
  4. שלב 3 — WhatsApp (אפשר לדלג): חיבור GREEN API ואישור התזכורות.
  5. שלב 4 — תנאים: קריאה ואישור של תנאי השימוש ומדיניות הפרטיות.

בסוף נוספות בגיליון ארבע עמודות עם 💰 — שולם · יתרה · מקור · תאריך תשלום. אלה העמודות של LessonDone: אפשר להקליד ב"שולם", את השאר המערכת ממלאת. לא למחוק אותן. בעמודות שלך המערכת לא נוגעת.

3. חיבור הטלפון

אנדרואיד — MacroDroid

  1. מתקינים MacroDroid מ-Google Play (חינם).
  2. בסיום ההתקנה בגיליון נשלחת אליך מאיתנו הודעת WhatsApp עם קובץ הגדרה אישי. שומרים את כרטיס איש הקשר של LessonDone.
  3. פותחים את הקובץ ← הוא נטען ל-MacroDroid ← מאשרים גישה להתראות.
  4. בודקים: מבקשים ממישהו לשלוח ₪1 ב-Bit. תוך דקות זה מופיע בגיליון.

אייפון 11 ומעלה (iOS 27) — קיצורים

  1. מקבלים מאיתנו קישור לקיצור ← "הוספת קיצור" ← מפעילים אותו פעם אחת עם הקוד האישי.
  2. באפליקציית הקיצורים ← אוטומציה ← "כשמתקבלת התראה" מ-Bit ומ-PayBox ← מריצים את הקיצור, בלי לשאול.
  3. בתוך Bit: פרופיל ← הרשאות והגדרות ← "קבלת נוטיפיקציות מ-bit" — דלוק.
  4. אפליקציה שהותקנה אחרי שיצרת את האוטומציה — נכנסים לאוטומציה ומוסיפים אותה.

מצב ידני (טלפון ישן)

אין חיבור לטלפון. כשמגיע תשלום — "✍️ הוסף תשלום" בסרגל (סעיף 6). כל השאר עובד אותו דבר.

4. שימוש יומי

  • ממשיכים לרשום שיעורים כרגיל. כלום לא משתנה באופן שבו את/ה עובד/ת.
  • תשלומים נכנסים לבד — בכל שעה (06:00–23:00), בכל פתיחה של הגיליון, ובכפתור "🔄 עדכן עכשיו". התשלום נרשם ב"💰 שולם" של השיעור הישן ביותר שעוד לא שולם, והיתרה מתעדכנת.
  • "💰 תשלומים נכנסים" — כל תשלום שזוהה והסטטוס שלו: 🟡 ממתין · 🟢 שויך · ⚪ לא רלוונטי · 🔴 חסום (הודעה שאינה תשלום).
  • "💰 ריכוז" — יתרה לכל תלמיד/ה וסה"כ. לקריאה בלבד; מתעדכן לבד.
  • סרגל הצד: "📊 סיכום חודשי", "👤 סיכום לתלמיד", "➕ תלמיד/ה חדש/ה".
  • קו ההתחלה — שיעורים מלפני יום ההתקנה הם היסטוריה: לא נספרים כחוב ולא נשלחת עליהם תזכורת.

5. תשלום שלא זוהה

אם השולח לא מוכר (למשל ההורה משלם בשם אחר), התשלום נשאר 🟡 "ממתין". בוחרים של מי הכסף — באחת משתי דרכים:

  • בחוצץ "💰 תשלומים נכנסים", בעמודה "👉 של מי?" — בוחרים תלמיד/ה מהרשימה.
  • או בסרגל: "🔗 שייך תשלום שהתקבל".

מהפעם הבאה המערכת זוכרת את המשלם. תשלום שלא קשור לשיעורים (למשל החזר חוב פרטי)? "לא רלוונטי לתשלומי שיעורים". טעית? מוחקים את הבחירה או בוחרים תלמיד/ה אחר/ת — השיוך מתבטל או עובר.

זיהוי תשלום הוא מידע בלבד, לא אישור שהכסף התקבל. אם יש ספק — בודקים באפליקציה של Bit או PayBox.

6. מזומן, העברה, או תשלום שלא נקלט

בסרגל: "✍️ הוסף תשלום במזומן / העברה" ← תלמיד/ה, סכום, אמצעי ותאריך. התשלום נרשם בדיוק כמו תשלום שזוהה לבד. אפשר גם להקליד סכום ישירות בעמודה "💰 שולם".

7. תזכורות WhatsApp להורים (לא חובה)

חיבור

  1. נרשמים ב-green-api.com. Developer (חינם) — עד 3 טלפונים שונים בחודש; Start (כ-$12 לחודש) — בלי הגבלה.
  2. יוצרים Instance וסורקים את קוד ה-QR מה-WhatsApp בטלפון (מכשירים מקושרים ← קישור מכשיר).
  3. בסרגל: "WhatsApp ותשלומים" ← "💬 הגדר WhatsApp" ← מדביקים idInstance ו-apiToken.
  4. מאשרים את התזכורות: רואים איך ההודעה נראית ולמי תישלח, ומסמנים את שתי התיבות.

מי מקבל ומתי

  • הורה עם יתרה על שיעור שעבר לפני יותר מ-3 ימים (עד 90 יום), שיש לו טלפון בגיליון.
  • בימים א׳–ה׳ בערב. לא יותר מפעם ב-48 שעות (אפשר לשנות ב"🔔 תדירות תזכורות", כולל כיבוי), ולכל היותר 3 פעמים על אותו חוב.
  • לא נשלח להורה שיש ממנו תשלום שממתין לשיוך, ולא לפני שהגיע התשלום הראשון מהטלפון.
  • הורה שכבר קיבל 3 תזכורות — מופיע בסרגל בשורת "🔕", כדי שתפנה/י אליו אישית.
  • חסר טלפון — שורת "📵" בסרגל עם כפתור להוספה.

מומלץ לשלוח להורים פעם אחת הודעה שמעכשיו ייתכן שיקבלו תזכורות (נוסח מוצע). GREEN API הוא שירות לא רשמי — יש סיכון שהמספר יוגבל; פרטים בסעיף 9 של תנאי השימוש.

בנוסף, פעם בשבוע לכל היותר, בערב, את/ה מקבל/ת הודעה אם הצטברו תשלומים שממתינים לשיוך.

8. מנוי

90 יום ניסיון חינם מההתקנה. אחר כך ₪29 לחודש; בלי חיוב אוטומטי. חידוש: בסרגל ← "הגדרות מתקדמות" ← חידוש מנוי. מנוי שלא חודש — הזיהוי והתזכורות נעצרים; הגיליון נשאר שלך כרגיל.

9. בעיות נפוצות

תשלום לא הופיע

"🔄 עדכן עכשיו". עדיין לא? בדוק/בדקי שהאוטומציה בטלפון פעילה ושיש לה גישה להתראות, ושההתראות של Bit / PayBox דלוקות. תשלום שהגיע לפני שהאפליקציה הותקנה — רושמים ידנית.

🔴 WhatsApp לא תקין

החיבור בטלפון פג (קורה אחרי כמה שבועות). נכנסים ל-console.green-api.com ← ה-Instance ← סורקים QR מחדש מה-WhatsApp בטלפון.

עמודת "💰 שולם" נמחקה

המערכת שומרת עותק ומחזירה את הסכומים לבד בסנכרון הבא. בסרגל תופיע הודעה עם אפשרות לבטל.

הסרה

בגיליון: תוספים ← ניהול תוספים ← LessonDone Lite ← הסרה. הגיליון ומה שנכתב בו נשארים.
